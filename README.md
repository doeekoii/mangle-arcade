# 멩글아케이드 부스 미니홈피

제주대학교 **멩글아케이드** 행사용 부스 미니홈피입니다. 부스마다 붙인 QR을 찍으면 그 팀의 싸이월드식 미니홈피가 열리고, 방문자는 방명록(닉네임/익명)과 명함을 남길 수 있어요.

- 호스팅: Vercel (빌드 없는 정적 사이트)
- 데이터: Supabase (Postgres + Storage)
- 주소 구조: `/#부스주소` = 부스 미니홈피, `/` = 부스 디렉터리, `/#admin` = 운영사 관리자

## 권한 구조
| 누가 | 할 수 있는 일 |
|---|---|
| 방문자 (로그인 없음) | 미니홈피 보기, 방명록 쓰기, 명함 보내기 |
| 팀 (팀 PIN) | 자기 부스 소개·로고 수정, 받은 명함 보기, 방명록 숨기기 |
| 운영사 (관리자 비밀번호) | 부스 일괄 등록, 팀 PIN 발급·재발급, 부스 삭제, 통계, QR 일괄 인쇄 + 모든 부스의 팀 권한 |

비밀번호는 저장소에 들어 있지 않아요. 모두 Supabase에 bcrypt 해시로 저장되고, 확인은 데이터베이스 함수에서만 해요. 같은 부스/관리자 비밀번호를 10분 안에 5번 틀리면 잠겨요.

## 처음 설정
1. Supabase에서 새 프로젝트를 만들어요 (리전: Northeast Asia (Seoul)).
2. SQL Editor에 `supabase/schema.sql` 전체를 붙여넣고 Run.
3. Project Settings → API 에서 Project URL과 `anon` `public` 키를 복사해 `config.js`에 넣고 커밋해요.
4. Vercel → Add New → Project → 이 저장소 Import → 설정 그대로 Deploy.
5. 배포된 주소 뒤에 `/#admin` 을 붙여 들어가서 관리자 비밀번호를 만들어요. (배포 직후 바로 해 주세요)
6. 관리자 화면에서 부스를 일괄 등록하면 팀 PIN이 발급돼요. 'QR 일괄 인쇄'로 부스용 QR을 출력해요.

## 행사 후
명함에는 개인정보가 들어 있어요. 행사가 끝나면 팀별로 명함을 전달한 뒤 Supabase에서 `cards` 테이블과 Storage `uploads/cards` 폴더를 비워 주세요.
